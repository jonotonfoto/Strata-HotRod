# Update — обновление установки HotRod

## Для агента
1. Запусти в корне установки: `python Update/update.py`
   (Windows: можно `Update\\update.bat`).
2. Установщик обновляет только код (`serve/`, `src/`, `include/`, `tools/`).
   Модели, конфиги `*.json`, `.bat`, `.venv`, `engine/` он не трогает.
3. Если есть git-клон — идёт `git fetch + merge --ff-only`. Если установка
   распакована из zip — качается архив с https://github.com/jonotonfoto/Strata-HotRod
   и заменяются только файловые копии кода (с бэкапом в `backups/update-<дата>/`).
4. Флаг `--dry-run` показывает изменения без записи. `--download` — forcing
   путь архива даже под git. `--ref` — другая ветка/хэш форка.
5. После успешного обновления попроси пользователя перезапустить сервер
   (сам сервер не перезапускай — у него идёт работа).
6. Если updater пишет про изменённые C-файлы — нужен пересбор движка,
   объясни это пользователю отдельно.

## Для человека
Двойной клик по `update.bat` — затем Enter на вопрос. Сервер после
обновления перезапусти своим батником запуска.

## Если папки Update в установке НЕТ (старая скачка)
Разово подтяни её из форка и запусти:
1. Скачай архив форка: https://github.com/jonotonfoto/Strata-HotRod/archive/refs/heads/main.zip
2. Из архива возьми ТОЛЬКО папку `Update/` в корень своей установки.
3. Запусти `Update/update.bat` (или agent: `python Update/update.py`).
