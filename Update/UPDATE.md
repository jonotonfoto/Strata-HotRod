# Update — обновление установки HotRod

Что нового в каждом обновлении и что после него включить: [CHANGELOG.md](CHANGELOG.md).

## Для агента
1. Запусти в корне установки: `python Update/update.py`
   (Windows: можно `Update\\update.bat`).
2. Updater обновляет код и документы: `serve/`, `src/`, `include/`, `tools/`, `docs/`, `Update/`.
   Модели, конфиги `*.json`, `.bat`, `.venv` он не трогает.
3. Если есть git-клон — идёт `git fetch + merge --ff-only` с того remote, который указывает на форк.
   Если установка распакована из zip — качается архив с https://github.com/jonotonfoto/Strata-HotRod
   и заменяются только изменившиеся файлы (с копией в `backups/update-<дата>/`).
4. **Движок.** Если движок в `engine/` собран из этого кода (`engine/BUILD.json`: `"source": "local"`) и код
   движка изменился, updater пересобирает его тем же шагом, что и установка: только изменённые файлы, обычно
   несколько минут. Что он пишет про движок и что делать:

   | Сообщение | Что делать |
   | --- | --- |
   | «собран из текущего кода» | ничего |
   | «пересобран» | попросить пользователя перезапустить сервер |
   | «движок сейчас РАБОТАЕТ» | код обновлён, движок прежний. Попросить пользователя закрыть сервер, потом запустить updater ещё раз |
   | «пересборка НЕ удалась» | прежний движок на месте и работает как раньше. Причина — выше в выводе; что нужно для сборки: `docs/SPEED_FIXES_SETUP.md`, раздел 2 |
   | «готовый, не собранный из этого кода» | правок форка в таком движке нет. Нужна установка с `--build`: `docs/SPEED_FIXES_SETUP.md`, раздел 2 |

5. Флаги: `--dry-run` — показать изменения, ничего не писать и не собирать; `--download` — качать архив даже под
   git; `--ref` — другая ветка или хэш форка; `--no-engine` — только код, движок не трогать.
6. Сам сервер не перезапускай и не останавливай: у пользователя может идти работа. Попроси его.
7. Конфиги updater не меняет, значит новые переключатели сами не включатся. Что добавить в `"env"` и с какими
   значениями для карты пользователя — в `CHANGELOG.md` и в `docs/SPEED_FIXES_SETUP.md`. Перед правкой конфига
   сделай его копию; ключ API из конфига не печатай.

## Для человека
Двойной клик по `update.bat` — затем Enter на вопрос. Если написано, что движок сейчас работает, — закрой сервер и
запусти `update.bat` ещё раз. После обновления запусти сервер своим батником.

## Если папки Update в установке НЕТ (старая скачка)
Разово подтяни её из форка и запусти:
1. Скачай архив форка: https://github.com/jonotonfoto/Strata-HotRod/archive/refs/heads/main.zip
2. Из архива возьми ТОЛЬКО папку `Update/` в корень своей установки.
3. Запусти `Update/update.bat` (или агент: `python Update/update.py`).

## Что проверено
Шаг с движком проверен тестами с подставным `setup.py` (`python Update/test_update.py`, 8 тестов: нет движка, готовый
движок, свежий, устаревший, неудачная сборка, проверка без записи) и в режиме чтения на одной настоящей установке
под Windows 10. Настоящая пересборка через updater не запускалась.

Сам файл `update.bat` updater не заменяет: Windows читает его по ходу выполнения.
