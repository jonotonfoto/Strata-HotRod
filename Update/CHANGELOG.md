# Что нового

Свежее сверху. Updater конфиги не меняет: всё из столбца «что включить» добавляется в `"env"` конфига сервера
руками или агентом, после чего сервер перезапускается.

## 27.11.2026 — быстрее чтение промпта

**Что изменилось.** Движок выбирает способ чтения промпта по длине запроса (`STRATA_PREFILL_PLAN2`). Короткий запрос
читается одним куском и занимает меньше видеопамяти; длинный читается так, что каждый эксперт едет на видеокарту
один раз на слой. По умолчанию выключено: без ключей движок читает как раньше.

**Что это дало** на RTX 4080 SUPER 16 ГБ, 64 ГБ ОЗУ, Windows 10, UD-Q4_K_XL:

| Чтение | Было | Стало |
| --- | --- | --- |
| короткие дочитывания, 87–1 123 токена | 21,2 с за пять | 18,3 с (−14%) |
| 12,5 тыс. токенов | 25,1 с | 16,7 с (−33%) |
| 33,6 тыс. с нуля | 58,1 с | 45,2 с (−22%) |
| 90,4 тыс. с нуля | 137,1 с | 96,4 с (−30%) |

Ответы модели и скорость генерации не хуже: 63 из 63 задач с оценкой против 61 из 63 без правки.

**Что включить.**

- Карта 16 ГБ, измерено:

  ```json
  "STRATA_PREFILL_PLAN2": "1",
  "STRATA_PREFILL_LM_MAP_MIB": "1600",
  "STRATA_PREFILL_LM_CHUNK": "10240"
  ```

- Карта 12 ГБ: **не измерено**. Значения для 16 ГБ туда не подходят. Порядок подбора на месте —
  `docs/SPEED_FIXES_SETUP.md`, раздел 3a, «A 12 GB card»; по-русски — `docs/PREFILL_PLAN.md`, «Карта 12 ГБ».
- Выключить: убрать все три строки.

**Что нужно, чтобы заработало.** Движок, собранный из этого кода. `update.bat` пересоберёт его сам, если сервер в
этот момент закрыт; если сервер работает — закрыть и запустить `update.bat` ещё раз.

**Ещё в этом обновлении.**

- `update.bat` теперь пересобирает движок и обновляет документы (`docs/`) и сам себя (`Update/`).
- Три переключателя для замеров, все выключены: `STRATA_PREFILL_EXPERT_STATS=1` (где лежали эксперты при чтении),
  `"prompt_trace_path"` в конфиге (почему движок прочитал промпт заново), `STRATA_PIN_SEGS_WIN=1` (закрепление
  памяти под Windows; чтения не ускорило).
- Скрипты замеров: `tools/prefill_plan/`.

Полная запись с замерами: `docs/PREFILL_PLAN.md`.

**Чего не проверено.** Другие видеокарты и объёмы памяти, Linux, несколько запросов сразу, работа сутки и дольше.
Почти все числа — по одному прогону. Собрано только под CUDA на Windows.
